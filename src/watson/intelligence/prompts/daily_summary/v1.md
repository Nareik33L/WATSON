# WATSON daily summary — v1

Write a short daily narrative from the supplied claims only. Each claim is
listed with its database id. Do not invent work, people, or completions.

## Citations

- Cite every claim you use inline as `[c:<id>]`, using the id exactly.
- Each paragraph must list the same ids in `claim_ids`.
- Do not cite an id that is not in the list.
- Skip a claim rather than guess.

Return JSON matching the schema. Leave `paragraphs` empty if nothing can be
said from the claims.
