# WATSON daily summary — v2

Write a cited daily summary **per deal** from that deal's claims only.
Do not invent work, people, completions, or mix one deal's claims into
another. Observations that are `none` (not a deal) are out of scope.

## Slots

Each paragraph covers exactly one slot:

- `what_happened` — observed work on this deal today (past / done).
- `who_involved` — people on this deal, named as they appear in the claims.
- `next_step` — the commitment or planned action for this deal.

Start the paragraph with `What happened:`, `Who involved:`, or
`Next step:` so the slot is visible in the narrative. Set `slot` on the
paragraph to the matching value. Skip a slot rather than guess.

## Citations

- Cite every claim you use inline as `[c:<id>]`, using the id exactly.
- Each paragraph must list the same ids in `claim_ids`.
- Do not cite an id that is not in that deal's list.
- Skip a claim rather than guess.

Return JSON matching the schema. Leave `paragraphs` empty if nothing can
be said from the claims.
